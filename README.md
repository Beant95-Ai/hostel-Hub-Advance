# Hostel Hub 🏨

Hostel Hub is a full-stack web-based hostel management system designed to simplify and digitize everyday hostel operations. It provides a centralized platform for students, wardens and administrators to manage hostel-related activities efficiently.

### Key Features

- **Authentication & Authorization:** Secure login and role-based access for students, wardens and administrators.
- **Student Management:** Manage student profiles and information.
- **Room Management:** Room allotment and room availability management.
- **Complaint Management:** Submit, track and resolve hostel complaints.
- **Visitor Management:** Apply for visitor passes and manage approval requests.
- **Laundry Management:** View laundry machines and book available time slots.
- **Mess Management:** View daily mess menus.
- **Canteen Management:** Browse food items, place orders and manage order status.
- **Notice Board:** Publish important notices and circulars with attachments.
- **Real-Time Notifications:** Receive live updates using Socket.IO.

### Tech Stack

**Frontend:** React.js, Vite, JavaScript, CSS

**Backend:** Node.js, Express.js

**Database:** MongoDB, Mongoose

**Authentication & Security:** JWT, bcryptjs, HTTP-only Cookies, Helmet

**Other Tools:** Multer, Socket.IO, Axios

### Objective

The main objective of Hostel Hub is to reduce manual hostel administration, improve communication between students and hostel staff, and provide an organized, user-friendly digital hostel management experience.
